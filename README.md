# 🧪 PDI — Laboratório de Qualidade de Software

Repositório destinado ao registro e desenvolvimento das atividades relacionadas ao **Plano de Desenvolvimento Individual (PDI)**, com foco em **qualidade de software, testes e evolução técnica**.

O objetivo deste repositório é servir como um ambiente de estudo e prática, permitindo aplicar os conhecimentos adquiridos durante o desenvolvimento profissional e registrar, de forma organizada, aprendizados, experimentos, documentações e resultados.

> **Status:** Em desenvolvimento 🚧

---

## 🎯 Objetivo

Este repositório tem como objetivo acompanhar a evolução das competências relacionadas à qualidade de software, explorando diferentes técnicas, ferramentas e abordagens de teste.

A proposta é utilizar atividades práticas para compreender melhor o processo de qualidade, desde a análise de requisitos e elaboração de cenários até a execução, documentação e análise dos resultados.

O conteúdo será desenvolvido progressivamente, de acordo com a evolução do PDI e das oportunidades de aprendizado.

---

## 📚 Áreas de aprendizado

Entre os principais temas que poderão ser explorados ao longo do desenvolvimento estão:

* Testes funcionais
* Testes manuais
* Testes exploratórios
* Técnicas de teste
* Elaboração de cenários de teste
* Gherkin
* Testes de API
* Validação de respostas HTTP
* SQL e validação de dados
* Identificação e documentação de inconsistências
* Testes de segurança
* Testes de performance
* Automação de testes
* Integração entre ferramentas
* Inteligência Artificial aplicada à qualidade de software
* Documentação e organização de testes

---

## 🧪 Laboratório de testes

Como parte da evolução prática, o repositório poderá conter uma aplicação ou API utilizada como **ambiente controlado para experimentação de diferentes técnicas de teste**.

A ideia é utilizar uma aplicação simples como objeto de estudo e, a partir dela, explorar diferentes abordagens de qualidade.

### Possíveis práticas

```text
Aplicação
   │
   ├── Testes funcionais
   ├── Testes exploratórios
   ├── Testes de API
   ├── Validação de dados
   ├── Testes de valores limite
   ├── Testes de segurança
   ├── Testes de performance
   └── Automação
```

As práticas serão adicionadas conforme o avanço do aprendizado e **não representam necessariamente atividades já concluídas ou projetos definidos**.

## 🤖 Inteligência Artificial

A Inteligência Artificial poderá ser utilizada como ferramenta de apoio durante o desenvolvimento das atividades.

Algumas possibilidades incluem:

* Geração inicial de cenários de teste;
* Revisão de casos de teste;
* Identificação de possíveis cenários negativos;
* Sugestão de casos de valor limite;
* Apoio na documentação;
* Análise de possíveis riscos;
* Comparação entre cenários produzidos manualmente e sugestões geradas por IA.

A utilização da IA será acompanhada de **validação humana**, considerando as regras de negócio e o contexto da aplicação.
